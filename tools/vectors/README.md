# Golden vectors

Test vectors for the C# port, generated by calling the Python reference (KalshiTerm2) as the oracle.
The generated JSON is committed under `tests/KalTerm.Core.Tests/Vectors/`; CI reads it and never runs
Python. Regenerate only when the reference changes, review the diff, and record the reference commit
(the generator writes it into each file).

```powershell
python tools/vectors/generate_fixedpoint.py --reference C:\Users\stebe\dev\KalshiTerm2
```

Requirements: Python 3.11+ and the standard library only. The reference clone is read, never edited.

Where the C# port is deliberately stricter or different from the reference, the vector says so
(`csharp` or `unsupported`), so every deviation is visible in the data rather than hidden in a test.
